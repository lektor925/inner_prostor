# Выгрузка из 1С:УПП

Код общего модуля для выгрузки номенклатуры и остатков в JSON, который
читает `import_1c` (см. [../catalog/management/commands/import_1c.py](../catalog/management/commands/import_1c.py)).
Контекст решений — [ADR-009, ADR-010, ADR-014](../assets/adr-spravochnik-nomenklatury.md).

## Что тут

- [`ВыгрузкаДляСправочника.bsl`](ВыгрузкаДляСправочника.bsl) — текст общего
  модуля на встроенном языке 1С. Разработано и протестировано в консоли
  запросов на копии `UPP_PL_VLAD` (запросы остатков/резерва и номенклатуры
  валидированы там же, см. ADR-014), но **сам модуль там ещё не заводился и
  не выполнялся** — только тексты запросов внутри него прогонялись по
  отдельности через консоль. Перед вводом в рабочую базу — прогнать целиком
  на копии.

## Установка (в Конфигураторе)

1. Открыть конфигурацию на **копии** `UPP_PL_VLAD` в режиме конфигуратора
   (ADR-009: разработка — на копии, боевой регламент — в рабочей базе).
2. Общие модули → добавить новый общий модуль, назвать `ВыгрузкаДляСправочника`.
3. Свойства модуля: `Сервер = Истина`, `Вызов сервера = Истина`. Клиентские
   свойства не нужны.
4. Вставить содержимое `ВыгрузкаДляСправочника.bsl`.
5. В функции `ПутьКПапкеВыгрузки()` указать реальный путь — общую с Django
   локальную папку (значение `IMPORT_DIR` из настроек Django, ADR-020: 1С и
   Django на одной машине).
6. Сохранить, обновить конфигурацию базы данных.

## Проверка вручную

Перед тем как заводить регламентные задания — выполнить процедуры вручную
(например, через обработку «Тестирование и исправление» → нет, проще: временно
добавить кнопку/обработчик, вызывающий `ВыгрузкаДляСправочника.ВыгрузитьНоменклатуру()`
и `ВыгрузкаДляСправочника.ВыгрузитьОстатки()`, либо выполнить через консоль
запросов «Выполнить код» при наличии такого режима в вашей версии консоли).
Проверить, что в папке выгрузки появились `nomenclature.json` и `stock.json`
без хвоста `.tmp`, и что `python manage.py import_1c --kind=reference` /
`--kind=stock` на Django-стороне отрабатывают без ошибок на этих файлах.

## Регламентные задания (боевая база)

Администрирование → Регламентные и фоновые задания → Регламентные задания →
добавить:

| Задание | Метод | Расписание (ADR-009) |
|---|---|---|
| Выгрузка номенклатуры | `ВыгрузкаДляСправочника.ВыгрузитьНоменклатуру` | ежедневно, ~03:00 |
| Выгрузка остатков | `ВыгрузкаДляСправочника.ВыгрузитьОстатки` | каждые 3-4 часа в рабочее время |

Django-сторона (Task Scheduler, ADR-010) должна читать файл через 10-15 минут
после начала окна 1С — оставить зазор на выполнение регламента.

## Известные допущения, требующие проверки на вашей базе

- Имя регистра резерва — `ТоварыВРезервеНаСкладах` (подтверждено на
  `UPP_PL_VLAD`, ADR-014). Если в рабочей базе конфигурация отличается —
  проверить, что регистр существует под этим именем.
- `Справочник.Склады` — запрос предполагает, что это иерархический
  справочник (`ЭтоГруппа`). Если у вас плоский список складов без папок —
  убрать условие `ГДЕ НЕ Скл.ЭтоГруппа` из `ПолучитьСклады()`.
- Единица измерения берётся из `Ном.БазоваяЕдиницаИзмерения.Наименование`
  (например, «шт», «м»). Базовая единица и единица хранения остатков в вашей
  базе всегда совпадают (подтверждено в сессии grill-me) — используется
  только базовая.
